# Security

This repository is the Home Assistant integration for
[Trobar](https://github.com/missing-foss/trobar-server). Trobar's threat
model, its hardening and its intentional access boundaries are described in
the server's
[SECURITY.md](https://github.com/missing-foss/trobar-server/blob/main/SECURITY.md).

## Reporting a vulnerability

Report it the way the server's
[SECURITY.md](https://github.com/missing-foss/trobar-server/blob/main/SECURITY.md#reporting-a-vulnerability)
describes, whichever Trobar repository it concerns. Please don't open a public
issue for anything exploitable until it's been addressed.
